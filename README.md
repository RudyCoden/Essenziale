# Essenziale

Sito statico per il salone Essenziale. È realizzato con HTML, CSS e JavaScript senza framework o dipendenze: può essere pubblicato gratuitamente con GitHub Pages.

## Prima di pubblicarlo

Aggiorna nella sezione **Contatti** di `index.html`:

- il numero di telefono e il collegamento `tel:`;
- il profilo Instagram e il relativo collegamento;
- l'indirizzo e la città.

Le fotografie sono caricate da Unsplash e richiedono una connessione a Internet. Per usare fotografie proprie, sostituisci gli URL `images.unsplash.com` in `styles.css`.

## Pubblicare con GitHub Pages

1. Crea un repository GitHub e carica questi file nella cartella principale.
2. Nel repository, apri **Settings → Pages**.
3. In **Build and deployment**, seleziona **Deploy from a branch**, scegli `main` e la cartella `/ (root)`, poi salva.
4. Attendi la pubblicazione: GitHub mostrerà l'indirizzo del sito nella stessa pagina.

Non serve acquistare un hosting. Se il repository si chiama `username.github.io`, il sito sarà disponibile all'indirizzo `https://username.github.io/`; per gli altri repository, Pages usa un percorso che include il nome del repository.
